Optional: put Deadlock's UI font files here so the browser preview uses the real fonts.
Until then the preview shows Oswald, a lookalike from Google Fonts.

Files are named Family-Weight.ext and become the matching font-family. The game's own names
(from citadel_base_styles) are VALVEPulp and Radiance, e.g.
  VALVEPulp-Regular.ttf   -> VALVEPulp   (titles, timers, banner)
  Radiance-SemiBold.ttf   -> Radiance, 600   (event names)

Where to get them: the fonts ship with the game. Look for font files in Deadlock's VPKs with
Source 2 Viewer. The fan wiki's font page (deadlock.wiki/Font) also links the .woff2 files.
They're Valve's fonts: use them for your own preview only and don't upload them anywhere.
The mod doesn't need them because the game already has them.
